Secrets

Inject API keys and credentials into containers as environment variables.

Secrets are encrypted key-value sets stored in your workspace. Attach them to a function and each key becomes an environment variable inside the container.

$ zephyr secret create huggingface HF_TOKEN=hf_xxx
@app.function(secrets=[zephyr.Secret.from_name("huggingface")])
def download():
    import os
    token = os.environ["HF_TOKEN"]

Secrets are never written to images or logs, and access is recorded in the workspace audit log.

Rotating a secret

Run zephyr secret create again with the same name. Running containers keep the old value until they restart.
