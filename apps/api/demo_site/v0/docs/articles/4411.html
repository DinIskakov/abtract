Volumes

Persist model weights and datasets on a network file system shared by all your containers.

Volumes are durable, replicated file systems that you mount into containers at a path of your choice. They are the right place for model weights, tokenizers, datasets and checkpoints.

weights = zephyr.Volume.from_name("model-cache", create_if_missing=True)

@app.function(gpu="A100", volumes={"/cache": weights})
def load():
    return torch.load("/cache/model.pt")

Writes become visible to other containers after weights.commit(). Use zephyr volume put and zephyr volume get to move files from your laptop.

Snapshots

Take a point-in-time snapshot with zephyr volume snapshot model-cache and restore it with zephyr volume restore.
