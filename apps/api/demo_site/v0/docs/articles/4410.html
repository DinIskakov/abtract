Scheduled jobs

Run functions on a cron or interval schedule with built-in retries.

Any function can run on a schedule. Zephyr keeps the schedule in the control plane, so nothing needs to stay running between invocations.

@app.function(schedule=zephyr.Cron("0 */6 * * *", timezone="Europe/Berlin"), retries=3)
def refresh_embeddings():
    ...

Use zephyr.Period(hours=1) for interval schedules. Overlapping runs are skipped by default; set allow_overlap=True to change that.

Pausing and history

Schedules can be paused and resumed from the dashboard, and the last 90 days of runs are kept with their logs.
