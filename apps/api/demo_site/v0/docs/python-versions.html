Python versions

Zephyr images ship with a CPython interpreter from python.org. Pick the version that matches your local environment so that pickled arguments round-trip cleanly.

Supported versions

VersionStatusNotes
Python 3.12Supported · DefaultUsed when python_version is omitted.
and more…

Choosing a version

Pass python_version when you build an image:

image = zephyr.Image.debian(python_version="3.11").pip_install("torch")

Versions that have reached end of life upstream are removed from the platform one release after their final security update.
