Limits & quotas

Platform limits that apply to every workspace. Enterprise customers can request higher limits through their account team.

Functions

Limits for containers started with @app.function, including web endpoints and scheduled jobs.

LimitValueNotes
Default timeout5 minutesOverride with timeout= on the decorator.
Maximum timeout12 hoursApplies to a single function call.
Maximum memory512 GiBRequested with memory= in MiB.
Maximum input size2 MiBArguments are pickled; pass large data through a volume.
Maximum output size8 MiBReturn values above this raise ResultTooLarge.
Concurrent containersDepends on planSee pricing.

Sandboxes

Sandboxes are interactive containers you start with zephyr.Sandbox.create(), for example to run untrusted code or an agent loop. Expand a limit to see its value.

Need more?

Enterprise workspaces can raise most of these limits. Contact us with the limit you need and the workload behind it.
