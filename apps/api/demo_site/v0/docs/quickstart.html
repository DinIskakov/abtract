Quickstart

Deploy your first GPU function in about five minutes. You need a working Python installation and a Zephyr account.

  1. Install the CLI

    The Zephyr CLI and Python SDK ship together in one package. Install it from PyPI:

    $ pip install zephyr-cli

    This puts the zephyr command on your path and makes import zephyr available.

  2. Authenticate

    $ zephyr login

    Your browser opens to confirm the device. The token is stored in ~/.zephyr/token.

  3. Write a function

    Save the following as hello.py. The decorator tells Zephyr which GPU to attach and which image to build.

    import zephyr

app = zephyr.App("hello")

@app.function(gpu="T4")
def gpu_info():
    import subprocess
    return subprocess.check_output(["nvidia-smi"]).decode()

if __name__ == "__main__":
    with app.run():
        print(gpu_info.remote())

  4. Run it, then deploy it

    $ zephyr run hello.py     # one-off run, streams logs to your terminal
$ zephyr deploy hello.py  # persistent deployment that scales to zero

    The first run builds and caches the image; subsequent runs start in well under a second.
