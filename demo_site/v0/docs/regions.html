    Pinning a function to a region

    By default Zephyr schedules a container in whichever region has capacity for the requested GPU. To keep compute next to your data, pin it:

    @app.function(gpu="A100", region="<region-id>")
def train(): ...

    Volumes are replicated to every region, so a pinned function can read the same data wherever it runs.
