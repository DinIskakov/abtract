Web endpoints

Expose any function as an HTTPS endpoint with a single decorator.

Add @app.web_endpoint() to a function and Zephyr serves it over HTTPS with autoscaling, TLS and request logging. Endpoints scale to zero between requests and back up in well under a second.

import zephyr

app = zephyr.App("api")

@app.function(gpu="L40S")
@app.web_endpoint(method="POST")
def generate(prompt: str, max_tokens: int = 256) -> dict:
    return {"text": run_model(prompt, max_tokens)}

After zephyr deploy the endpoint is available at https://<workspace>--api-generate.zephyr.run. Query parameters and JSON bodies are mapped to function arguments automatically.

Streaming

Return a generator to stream the response as server-sent events. Set websocket=True on the decorator for bidirectional streaming.

Authentication

Endpoints are public by default. Pass requires_proxy_auth=True to require a workspace token in the Authorization header.
